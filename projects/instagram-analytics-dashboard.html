01 / PROJECT OVERVIEW

What this system is designed to do

An automated Instagram reporting pipeline that collects account, post, Reel, audience and advertising metrics through Meta Graph API and organizes them for analysis and executive reporting.

The solution is implemented as an n8n-led workflow using the integrations and logic described below. The focus is to connect the input, processing steps and destination systems into a traceable flow. n8n workflows retrieve data from relevant Meta Graph API endpoints, transform and calculate metrics, then update structured Google Sheets datasets used by the reporting dashboard.

02 / BUSINESS CONTEXT

The problem and objective

Instagram performance data is spread across account, content, audience and advertising insights. Reviewing these separately makes it harder to get a consistent view of what is happening across the account.

Objective: Build a repeatable workflow that connects the relevant data or event to the appropriate processing logic and records the result in the systems used by the team.

03 / IMPLEMENTATION SCOPE

What I implemented

  • Automated daily extraction and synchronization
  • post and Reel performance tracking
  • organic reach, views, engagement, watch time and follows
  • audience age, gender and geography

  • ad spend, reach, impressions and conversion metrics
  • follower versus non-follower reach
  • engagement, share, save and follow rates
  • category-wise classification
