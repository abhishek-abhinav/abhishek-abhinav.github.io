01 / PROJECT OVERVIEW

What this system is designed to do

A form-driven quotation workflow that processes submitted details, generates a PDF quotation and delivers it by email.

The solution is implemented as an n8n-led workflow using the integrations and logic described below. The focus is to connect the input, processing steps and destination systems into a traceable flow. The form acts as the input layer, the webhook passes data into the automation, and the workflow creates and emails the resulting PDF.

02 / BUSINESS CONTEXT

The problem and objective

Preparing quotations manually from submitted details can involve repetitive data entry, document creation and email delivery. This workflow connects those steps.

Objective: Build a repeatable workflow that connects the relevant data or event to the appropriate processing logic and records the result in the systems used by the team.

03 / IMPLEMENTATION SCOPE

What I implemented

  • Receive form submissions through a webhook
  • map submitted fields
  • process quotation data
  • generate a PDF document
  • send the generated quotation by email
