01 / PROJECT OVERVIEW

Purpose and scope

A review workflow that evaluates posts published within a selected timeframe, assigns post-level scores and verdicts, then consolidates findings into a practical feedback and action plan.

The workflow scopes the posts by the selected time window, gathers the relevant performance information, processes each post through the evaluation logic and combines the individual results into one review output for the team.

02 / DETAILED IMPLEMENTATION

What was built and how it works

The following points reflect the documented project scope and workflow activities.

  • Select posts published within a defined timeframe.
  • retrieve the available post-performance information.
  • evaluate each post individually.
  • produce a post-wise score and verdict.
  • consolidate the post evaluations.
  • prepare one comprehensive feedback summary.
  • generate an action plan from the evaluation output.
